# Agentic Co blog

Jekyll, built natively by GitHub Pages — no CI step, no plugins outside the
`github-pages` allowlist. Pushing to the default branch publishes it.

Local preview (needs Ruby + Bundler):

    bundle install
    bundle exec jekyll serve

Posts live in `_posts/`, ordered on the index by `series_order` rather than by
date, because they are a numbered series.
